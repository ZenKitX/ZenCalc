# 科学计算器实现计划

## 参考设计
根据提供的参考图，科学计算器布局应该是：

### 基础模式（4x5布局）
```
AC  %   ⌫   ÷
7   8   9   ×
4   5   6   -
1   2   3   +
00  0   .   =
```

### 科学模式（5x7布局）
```
sin cos tan rad deg
log ln  (   )   inv
!   AC  %   ⌫   ÷
^   7   8   9   ×
√   4   5   6   -
π   1   2   3   +
e   00  0   .   =
```

## 实现步骤

1. ✅ 创建科学计算逻辑文件 `scientific_calculator_logic.dart`
2. ⏳ 在 calculator_view.dart 中添加模式切换状态
3. ⏳ 添加科学模式切换按钮
4. ⏳ 创建科学计算器按钮布局
5. ⏳ 修改计算逻辑以支持科学函数
6. ⏳ 测试所有功能

- [x] log (log10)

## 注意事项

1. 保持禅意设计风格
2. 按钮使用 Neumorphic 风格
3. 科学模式按钮字体稍小（fontSize: 14）
4. 模式切换有平滑动画
5. 科学函数输入需要特殊处理
