# ZenCalc v1.0.3 发布说明

## 发布日期
2026-03-02

## 主要更新

### 🔬 科学计算器功能

ZenCalc v1.0.3 引入了全新的科学计算器模式，在保持禅意设计风格的同时，为用户提供强大的科学计算能力。

#### 科学函数支持

**三角函数**
- `sin` - 正弦函数
- `cos` - 余弦函数
- `tan` - 正切函数

**对数函数**
- `log` - 常用对数（以10为底）
- `ln` - 自然对数（以e为底）

**幂运算**
- `xʸ` - 任意幂运算（使用 ^ 符号）
- `√` - 平方根（sqrt）

**其他功能**
- `( )` - 括号支持，处理运算优先级
- `π` - 圆周率常数（3.14159...）
- `e` - 自然常数（2.71828...）

### 🎨 用户界面改进

#### 模式切换
- 顶部工具栏新增"基础/科学"切换按钮
- 一键切换计算器模式
- 平滑的动画过渡效果
- 切换按钮采用禅意配色，激活时显示强调色

#### 科学模式布局
- 7行5列的紧凑布局
- 35个按钮，包含所有科学函数
- 按钮间距优化为3px，提供更多空间
- 科学函数按钮字体为14px，保持清晰可读

#### 基础模式布局
- 保持原有的5行4列布局
- 20个按钮，专注于基础运算
- 按钮间距为4px，提供舒适的点击体验

### ⚙️ 技术实现

#### 科学计算引擎
- 新增 `scientific_calculator_logic.dart` 模块
- 支持复杂表达式解析和计算
- 括号优先级正确处理
- 科学计数法显示（对于极大或极小的数）
- 错误处理和边界情况处理

#### 代码架构
- 模块化设计，基础和科学计算逻辑分离
- 使用 `AnimatedSwitcher` 实现平滑切换
- 保持 Neumorphic 设计风格一致性
- 响应式布局，适配不同屏幕尺寸

### 📐 使用示例

#### 基础运算
```
2 + 3 × 4 = 14
```

#### 科学运算
```
sin(π/2) = 1
log(100) = 2
2^10 = 1024
sqrt(16) = 4
(2+3)×4 = 20
```
