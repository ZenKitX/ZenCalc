# 单位换算功能设计方案

## 概述

为 ZenCalc 添加单位换算功能，支持多种常用单位类别的转换，保持禅意设计风格。

## 功能范围

### Phase 1: 基础换算（优先实现）
1. **长度** - Length
   - 米(m)、千米(km)、厘米(cm)、毫米(mm)
   - 英尺(ft)、英寸(in)、码(yd)、英里(mi)

2. **面积** - Area
   - 平方米(m²)、平方千米(km²)、平方厘米(cm²)
   - 公顷(ha)、亩、平方英尺(ft²)、平方英里(mi²)

3. **重量** - Weight
   - 千克(kg)、克(g)、毫克(mg)、吨(t)
   - 磅(lb)、盎司(oz)、斤、两

4. **温度** - Temperature
   - 摄氏度(°C)、华氏度(°F)、开尔文(K)

### Phase 2: 进阶换算
5. **体积** - Volume
   - 立方米(m³)、升(L)、毫升(mL)
   - 加仑(gal)、品脱(pt)、立方英尺(ft³)

6. **速度** - Speed
   - 米/秒(m/s)、千米/时(km/h)
   - 英里/时(mph)、节(knot)

7. **压强** - Pressure
   - 帕斯卡(Pa)、千帕(kPa)、兆帕(MPa)
   - 巴(bar)、大气压(atm)、毫米汞柱(mmHg)

8. **功率** - Power
   - 瓦特(W)、千瓦(kW)、兆瓦(MW)
   - 马力(hp)

### Phase 3: 特殊换算
9. **进制转换** - Number System
   - 二进制、八进制、十进制、十六进制

10. **汇率换算** - Currency（需要 API）
    - 人民币(CNY)、美元(USD)、欧元(EUR)、日元(JPY)等
    - 实时汇率更新

11. **房贷计算** - Mortgage（计算器）
    - 等额本息、等额本金
    - 贷款总额、利率、期限计算

### 2. 数据模型

#### ConversionCategory（换算类别）
```dart
class ConversionCategory {
  final String id;              // 类别ID
  final String name;            // 类别名称
  final IconData icon;          // 类别图标
  final List<ConversionUnit> units;  // 支持的单位列表
  final bool requiresApi;       // 是否需要API（如汇率）
}
```

#### ConversionUnit（单位）
```dart
class ConversionUnit {
  final String id;              // 单位ID
  final String name;            // 单位名称
  final String symbol;          // 单位符号
  final double toBaseRatio;     // 转换到基准单位的比率
}
```

### 3. 换算逻辑

#### 基本换算公式
```
结果值 = 输入值 × (输入单位比率 / 输出单位比率)
```

#### 特殊处理
- **温度**：需要特殊公式（非线性）
  - °C → °F: (°C × 9/5) + 32
  - °F → °C: (°F - 32) × 5/9
  - °C → K: °C + 273.15
  
- **进制**：使用 Dart 内置方法
  - `int.parse(value, radix: base)`
  - `value.toRadixString(base)`

### 4. 状态管理
使用 GetX 进行状态管理：
- 当前选择的类别
- 输入值和输出值
- 选择的输入单位和输出单位
- 实时换算结果

## 交互流程

1. **进入换算模式**
   - 点击顶部"换算"按钮
   - 显示类别选择界面

2. **选择类别**
   - 点击类别卡片
   - 进入换算详情界面

3. **输入和换算**
   - 默认显示该类别的第一个和第二个单位
   - 用户输入数值
   - 实时显示换算结果

4. **切换单位**
   - 点击单位选择器下拉菜单
   - 选择新单位
   - 自动重新计算

5. **交换单位**
   - 点击中间的交换按钮
   - 输入和输出单位互换
   - 数值同步更新

6. **返回**
   - 点击左上角返回按钮
   - 返回类别选择界面

## 设计规范

### 1. 颜色方案
保持与计算器主界面一致的禅意配色：
- 背景：浅色模式 `#E8E4DC`，深色模式 `#1A1A1A`
- 卡片：Neumorphic 效果
- 强调色：竹绿色 `#6B8E23`

### 2. 动画效果
- 类别卡片：点击时的缩放动画（0.95x）
- 页面切换：滑动过渡动画（300ms）
- 单位交换：旋转动画（400ms）
- 结果更新：淡入淡出（200ms）

### 3. 字体大小
- 类别标题：18px
- 输入/输出值：32px
- 单位名称：16px
- 键盘按钮：20px
