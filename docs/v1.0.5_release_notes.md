# ZenCalc v1.0.5 发布说明

## 🎉 重大更新：单位换算功能

ZenCalc v1.0.5 带来了全新的单位换算功能，支持 9 大类别、60+ 单位的实时换算。

## ✨ 新增功能

### 单位换算系统

#### 支持的换算类别

1. **长度换算** 📏
   - 米(m)、千米(km)、厘米(cm)、毫米(mm)
   - 英尺(ft)、英寸(in)、码(yd)、英里(mi)

2. **面积换算** 📐
   - 平方米(m²)、平方千米(km²)、平方厘米(cm²)
   - 公顷(ha)、亩、平方英尺(ft²)、平方英里(mi²)

3. **重量换算** ⚖️
   - 千克(kg)、克(g)、毫克(mg)、吨(t)
   - 磅(lb)、盎司(oz)、斤、两

4. **温度换算** 🌡️
   - 摄氏度(°C)、华氏度(°F)、开尔文(K)

5. **体积换算** 🧊
   - 立方米(m³)、升(L)、毫升(mL)、立方厘米(cm³)
   - 加仑(gal)、品脱(pt)、立方英尺(ft³)

6. **速度换算** 🚀
   - 米/秒(m/s)、千米/时(km/h)
   - 英里/时(mph)、节(kn)、英尺/秒(ft/s)

7. **压强换算** 💨
   - 帕斯卡(Pa)、千帕(kPa)、兆帕(MPa)
   - 巴(bar)、大气压(atm)、毫米汞柱(mmHg)、磅/平方英寸(psi)

8. **功率换算** ⚡
   - 瓦特(W)、千瓦(kW)、兆瓦(MW)
   - 马力(hp)、BTU/时(BTU/h)

9. **进制转换** 🔢
   - 二进制(BIN)、八进制(OCT)
   - 十进制(DEC)、十六进制(HEX)

### 核心特性

- **实时换算**：输入即换算，无需按等号
- **单位交换**：一键交换输入输出单位
- **智能键盘**：
  - 普通换算：标准数字键盘
  - 进制转换：支持 A-F 字母的专用键盘
- **输入验证**：进制转换时自动验证输入合法性
- **禅意设计**：保持 Neumorphic 风格，与计算器主界面一致

### UI/UX 改进

- **类别选择界面**：网格布局，清晰展示所有换算类别
- **换算详情界面**：
  - 上下两个卡片分别显示输入和输出
  - 中间圆形交换按钮
  - 单位选择器支持底部弹窗选择
  - 实时显示换算结果
- **顶部工具栏**：新增换算入口按钮（交换图标）

### 核心算法

#### 基本单位换算
```dart
结果值 = 输入值 × (输入单位比率 / 输出单位比率)
```

#### 温度换算（非线性）
- °C → °F: (°C × 9/5) + 32
- °F → °C: (°F - 32) × 5/9
- °C → K: °C + 273.15

#### 进制转换
- 使用 Dart 内置方法
- `int.parse(value, radix: base)`
- `value.toRadixString(base)`

## 🚀 使用指南

### 快速开始

1. **打开换算功能**
   - 点击顶部工具栏的换算按钮（交换图标）

2. **选择类别**
   - 在网格中点击需要的换算类别

3. **输入和换算**
   - 使用键盘输入数值
   - 实时查看换算结果

4. **切换单位**
   - 点击单位名称打开选择器
   - 选择新单位自动重新计算

5. **交换单位**
   - 点击中间的交换按钮
   - 输入输出单位互换

### 进制转换特别说明

- 进制转换使用专用键盘（包含 A-F）
- 自动验证输入合法性
- 不支持小数点
- 大小写不敏感（自动转大写）

## 📈 性能优化

- 实时换算采用响应式编程（GetX）
- 输入验证防止非法计算
- 智能键盘按需切换
- 高精度浮点运算（8位小数）

## 🐛 已知问题

- 进制转换暂不支持负数
- 极大数值可能显示为科学计数法
- 部分单位换算精度限制在 8 位小数
